# 칼림바 악보

칼림바 숫자 악보를 만들어 **A4 PDF**로 저장하는 아이패드용 웹앱.

## 쓰는 법

1. 사파리로 주소를 연다
2. 공유 버튼 → **홈 화면에 추가**
3. 홈 화면 아이콘으로 실행

## 기능

| 기능 | 설명 |
|------|------|
| 계이름 입력 | 터치 키패드로 `1`~`7` 입력. 옥타브는 숫자 위 점으로 표시 |
| 옥타브 | 기본 · 한 옥타브 위(점 1개) · 두 옥타브 위(점 2개) |
| 건반 수 | 17건반 / 21건반 — 쓸 수 있는 음이 자동으로 바뀐다 |
| 길게 누르기 | `—` 를 넣으면 앞 음의 칸이 늘어난다 |
| 줄 관리 | 줄 추가 · 복제 · 삭제 · 아래 띄우기 |
| 칸 수 | 한 줄에 4 ~ 16칸 |
| 색칠용 손 | 연주한 만큼 색칠하는 손 그림. 개수 조절 |
| 저장 | 아이패드 안에 자동 저장 (여러 곡) |

## PDF 저장

버튼이 두 개다. 기기에서 되는 쪽을 쓰면 된다.

| 버튼 | 방식 |
|------|------|
| 인쇄로 저장 | 브라우저 인쇄 화면 → `PDF로 저장` |
| PDF 저장 | 앱이 직접 PDF를 만들어 공유 시트로 전달 |

## 구조

```
index.html      화면
style.css       스타일 + A4 인쇄 규격
app.js          로직 (미리보기와 PDF가 같은 좌표를 공유)
assets/         색칠용 손 그림
lib/            jsPDF
sw.js           오프라인 동작
```

## 로컬에서 보기
